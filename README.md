## About Me

I'm a **Backend & AI Engineer** focused on building scalable backend systems and production-oriented AI applications.

My work sits at the intersection of **backend engineering, distributed systems, and AI**, with a particular interest in building systems where LLMs, retrieval pipelines, asynchronous workers, databases, and APIs work together as a single production architecture.

I enjoy working on problems involving:

* ⚙️ Scalable backend APIs and service architecture
* 🤖 Agentic AI and LLM-powered applications
* 🔎 RAG and semantic search systems
* 🧠 AI-driven investigation and automation
* 🗄️ PostgreSQL and vector databases
* ⚡ Async processing with Celery and Redis
* 🐳 Containerized development with Docker
* ☁️ Cloud-based AI infrastructure
* 🔧 System reliability, testing, and observability
